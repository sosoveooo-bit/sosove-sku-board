# 对话创作室策划提速计划

**Goal:** 在保留全部来源文字、参考图和在线七层Brief质量的前提下减少重复策划/编译与排队等待。

**Architecture:** 浏览器用完整需求、市场/模式/页数/尺寸、参考文件名类型及内容SHA256绑定已完成方案；命中时无新增导演请求，显式“重新AI策划”可绕过。代理端只缓存确定性编译产物（原文+完整方案+编译版本键，限8项），在已认证上游响应后使用。共用公司模式默认3批并发，拥堵后续轮/重试降2；保持用户超时与模型设置。已完成页面续写和单页重生成维持原流程。

**Validation:** 浏览器精确命中/修改输入失效/强制重做；编译cache命中/变更原文与页内容失效/返回副本隔离；调度默认值与拥堵降并发；旧有超时、缺页与市场回归。性能比较只测本地模拟与确定性工作，不消费AI额度，也不承诺实际端到端提速比例。

**Deployment:** 等现有任务结束后重载8793/8795，验证健康与公网资源；不改节点、token、模型配置或既有任务。
