# JP25 默认视觉与日文卖点修复

用户反馈：工作台增加后，成图仍与之前相似，希望接近 Giikin 参考页面的精致程度。

## 核实的问题

- 第一轮工作台增加方案编辑、试样、续生成和检查报告；空调整不会改变默认提示词，实际任务仍使用 v34。
- 日文 `主なポイント` 编号段落、`サブポイント` 中点列表没有正确保留。主标题里的 `、` 被误分成独立卖点，原始说明和子卖点没有正确绑定页面。
- 已查看近期两张实际输出和参考网站的服装细节页；目前大标题与全身站姿较多，参考细节图的产品占比、近景证据与克制文字值得借鉴。此观察不是模型效果对比实验。

## 实施

1. JP25 专用日文结构解析器：完整保留编号标题、后续说明及中点子卖点，区分主/子卖点，遇全局要求停止。保持原有中文解析入口。
2. 整套策划与第二轮逐页导演加入默认艺术指导：主图和详情采用不同证据尺度；车线/结构可近看，比例使用完整穿着画面，搭配要实际变化。
3. 整套 visualBible 增加字体、版式与材质处理；传入保存后的页面和最终执行提示词。默认控制光影、真实织理、主体与环境层次、紧凑日文标题。用户明确布局、配色和人物要求优先。
4. 最终执行路径始终添加精修要求，即使工作台全局与逐页调整为空。原参考图路由、人物与产品一致性、完整卖点、七层导演方案继续生效。
5. JP25 计划和参考分析缓存升级至 v35 / v7，前端资源更新。旧任务显示重新策划提示，旧成图保留。

## 验证与边界

- 回归用日文示例验证 3 个主卖点、5 个子卖点，完整说明贯穿 25 页编译，精修要求在无手动调整时也进入最终请求。
- 验证共享视觉规范经计划标准化、逐页导演和最终提示词后仍保留。
- 全部验证使用固定数据/模拟模型，不提交真实生图或付费模型请求。真实成图的精致程度仍需新版试样确认，不能由提示词测试代替。
- 当前服务没有运行中生成任务时才重启加载后端；不清除图片、方案、配置或历史。
