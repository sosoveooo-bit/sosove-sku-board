# 移除独立商品身份填写区

用户明确要求删除“产品身份与交付资料 · 可修正产品识别”。

## 范围

- 移除整个填写区、保存按钮、保存/另存资料修正任务逻辑和前端事件。
- 同时移除后端独立身份确认阻塞步骤，避免删除 UI 后仍等待该输入。
- 新产品分析不再要求 identityAssessment 输出。旧缓存中的该对象不再参与暂停流程，其资料冲突并入原有 missingInformation，仅供策划了解不确定信息。保留事实状态，未核实内容不会自动变成确认事实或成图证言。
- 历史身份确认错误提示提供“继续策划”，清理指向已删除输入框的旧提示。
- 不更换产品缓存版本，不批量删除或改写数据。旧任务的 productFacts 字段保留用于已有请求哈希和接口兼容；已有图片、计划、补图状态继续可用。

## 验证

离线验证旧身份冲突缓存可直接复用并继续剩余阶段、新分析省略身份表单字段、缓存原文及不确定事实保留。前端验证组件和事件均不存在、旧错误可续跑、历史材料和请求数据保留。未新增模型调用，也未触发生图。

执行结果：81 项 Visual Agent Python 测试、6 组 JS 回归、JS 语法检查和相关 Python 编译检查通过。确认没有活跃策划或生图任务后重载 8793。
