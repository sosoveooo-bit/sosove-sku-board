# COD submission and copy repair

## Reproduced failures
- Same saved Japanese brief submitted through FormData contains CRLF; JSON preflight
  contains LF. The old fingerprint check rejected the unchanged request. Verified
  against the current 20-page production checkpoint before and after the fix.
- Per-copy language validation required Japanese script in every label, including
  documented English package names. The current first page contains literal
  `Topacme` and `3D Relief Art Pen` labels alongside Japanese headline/support text.
- One invalid copy entry stopped the entire batch, despite other pages already saved.
- Live dispatch exposed an additional multipart defect: Agent reference validation
  consumed upload streams, then dispatch re-read the streams and saw empty files.
  The old transport-mocked tests did not expose stream consumption.

## Changes
- Compare equivalent newline encodings at submission only. Keep existing cache keys
  and saved input hashes; still reject actual brief, country, size and count changes.
- Permit short Latin package labels only when present verbatim in product visual
  identity. Headline/support copy still needs the selected language.
- Persist failed drafts and validation feedback. Repair only missing/invalid pages
  once per batch; retain successful prompts. Shared deadline and cancellation checks
  continue to apply. No generated-image AI review added.
- Clear old repair drafts when product or creative analysis is explicitly reset.
- Reuse the exact verified reference bytes on image dispatch instead of reading
  upload streams twice. Added a real BytesIO upload-path regression test.

## Verification
- Unit tests cover grounded labels, foreign headlines, page-only repair, bounded
  failure, resume, newline transport equivalence and actual request changes.
- Production continuation uses the existing 20-page JP checkpoint and exact hashes
  of the eight original reference files. Product analysis is guarded against rerun.
- Live planning/image results are recorded in the workspace `.run/cod-live-*.json`.
  These are local operational artifacts, not repository fixtures.
- Live result: all 20 prompts completed using the product cache. One paid page
  returned successfully through the existing Fivio node in 78,972 ms, material
  `AI-9F6987A9A5`, actual PNG dimensions 750 x 1000, 1,093,892 bytes. No post-image
  model call. The remaining 19 images were not generated by this verification.
- 56 Python visual-agent tests and frontend submission/error/reference regressions
  passed. Local 8793 service reloaded and health verified.
