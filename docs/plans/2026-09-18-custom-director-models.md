# 自定义导演模型

## 范围
- 导演模型下拉增加 `deepseek-v4.1-flash`，保持当前选择和生图模型不变。
- 下拉旁增加自定义名称输入与“添加并选用”；点击“保存配置”后在服务端持久保存列表。
- 模型目录与备用请求链分离：新增可选模型不自动增加失败重试。
- 保留管理员权限、旧设置兼容、密钥处理、产品缓存和原图片生成接口。

## 实现与验证
1. backend.py：独立可选模型目录、customModels 校验/保存/返回；支持任意有效 ID，不做提供商白名单。
2. static/index.html、static/app.js、static/styles.css：新增控件，合并内置/自定义/当前模型，保存草稿，Enter 只添加而不提交生图。
3. 离线测试：跨保存与重载持久化、旧配置迁移、精确模型名透传、权限与密钥、去重/长度/格式、备援链不扩张、前端渲染和异步刷新。
4. 确认任务空闲后重载 8793，检查健康与实际发布资源。添加和保存不调用收费模型；上游可用性及识图支持由所配置 API 决定。
