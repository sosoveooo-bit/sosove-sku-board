# 所选市场全链路修复计划

**Goal:** 对话创作室19个市场以下拉框为准，防止参考国家名改变目标；COD分析、逐页导演与最终图片同用市场约束。

**Architecture:** workflow.js取消从原文自动改country；记录方案市场与规则版本。共用COD引擎补全market_localization.py，复用已有本地化profile并添加场景轮换与语言区分；在产品分析、线上七层导演和远程七层直出编译路径注入同一约束。跨市场旧方案报错而非静默生成；只更新COD缓存版本。

**Verification:** 19市场前端参数与浏览器保持测试；38条两种COD编译路径测试；跨市场方案拦截；旧元数据刷新；已有英语市场回归。无付费生图测试。

**Preservation:** 用户原文、商品、明确人物身份、数字和使用方法保留；不强制某种族肤色、不增地标/国旗。不添加生成后AI质检。已有图片和后台任务不删除。
