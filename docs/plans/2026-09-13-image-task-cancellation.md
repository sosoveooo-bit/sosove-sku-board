# 原面板与对话创作室任务取消

**Goal:** 始终提供取消入口，取消后不再提交未发出的策划/图片请求，排队任务停止；刷新不等于取消。

**Architecture:** 每次前端生成流程分配并持久化operationId；后台用owner+operationId保存七天取消标记。取消接口先验证任务归属再写标记，支持任务编号回退。规划调用和图片工作线程携带取消上下文，线程池传播上下文，在导演重试和provider POST前检查。已发往上游的请求不冒充撤销，继续取回已有结果并保留图片；中止排队任务持久化为cancelled，重启不续跑。

**UI:** 原面板固定取消按钮，不依赖生成按钮切换；8795保留暂停并新增取消。明确展示请求确认/未确认与上游仍可能执行计费。取消接口请求自身不随AbortController中断。旧方案、图片保留。

**Validation:** owner隔离、晚到提交阻止、排队任务零provider请求、在途结果保留、线程池上下文传播、重启标记恢复；无真实模型或生图调用。等待现有任务结束后部署，固定8795项目venv。
