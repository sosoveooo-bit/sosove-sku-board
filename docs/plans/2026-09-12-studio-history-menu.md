# 对话历史菜单实施计划

**Goal:** 在8795历史对话上添加右键/更多菜单，支持持久重命名、收藏置顶、确认删除。

**Architecture:** 复用账号隔离的 IndexedDB sessions；菜单绑定目标ID，而非当前会话；事务成功后更新内存。删除只删除本浏览器会话（含其参考文件和任务索引），保留原引擎文件和后台任务。原页面、模式路由、节点不变。

**Tech Stack:** 原生JS、HTML dialog、CSS、Node与隔离Playwright测试。

1. app.js：会话存储支持指定记录；历史行拆成选择按钮与更多按钮；收藏优先排序和搜索保持兼容；手动命名不被新需求覆盖。
2. history-menu.js/css：右键、更多和Shift+F10/菜单键入口；视口内定位；方向键、Escape、外部点击关闭；重命名/删除弹窗确认；忙碌或写入时防止竞态；每次操作核对owner。
3. server.py/index.html：仅添加静态文件白名单和脚本加载；无后台删除API。
4. test_browser.cjs扩展或独立测试：右键非当前记录、重命名刷新保留、收藏置顶与取消、搜索、删除取消/确认/最后一条、键盘关闭、安全转义、无真实生图请求。
5. 跑既有回归测试、截图核验；部署8795静态资源，按需要只重启8795。公网资源加载复核。
