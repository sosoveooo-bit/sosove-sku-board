# Amazon A+ 服装生图质量优化实施计划

> 日期：2026-08-25  
> 范围：仅 `amazon-jp-aplus-9`；不触发实际生图，不改动 Linkfox/ChatGPT2API 凭据。

## 目标

把 Amazon A+ 服装链路收敛为一条清晰的生产管线：本地 Linkfox Skill 只负责编排，ChatGPT2API 文本模型把结构化商品事实编译成简洁的无字底图提示词，`gpt-image-2` 使用原生横图尺寸生成，面板满版裁切为 970×600 后再以真实日文字体写入标题。

## 实施顺序

1. 先补覆盖以下行为的失败测试：结构化服装事实契约、零模型文字、Amazon 默认精确排版、原生横图请求、满版裁切、服装专属质检、前端状态及 Skill 版本。
2. 新增紧凑的 Amazon 页面契约，只保留商品事实、服装结构、当前页卖点与拍摄参数；原始长提示词仅作为限长事实兜底，不再追加到最终渲染提示词。
3. Amazon 请求 ChatGPT2API 时使用 1536×1024，最终输出仍固定为 970×600；归一化采用居中满版裁切，消除灰边和空带。
4. Amazon 默认启用程序化日文排版。模型只生成无字底图并预留低细节安全区，面板选择顶部低复杂度区域，以系统日文字体写入精确标题。
5. 增加服装结构一致性、背面证据、九图差异、零模型文字及满版画布的专属质检规则，并在前端公开实际链路状态。
6. 运行 Python/JavaScript/JSON 静态检查、Amazon 定向测试和完整 AI 生图测试；重启 8793 面板并仅做无扣费的界面验证。

## 非目标

- 不调用 Linkfox Agent API，不上传参考图到 Linkfox OSS。
- 不改变乐天、JP25、COD 或普通单图的默认排版和裁切策略。
- 不执行真实图片生成或自动重试付费任务。
- 不提交 Git，不覆盖工作区已有的无关修改。
