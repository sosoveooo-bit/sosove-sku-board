# GitHub 随仓库发布版本

此目录是对话创作室发布源码。后端位于同仓库的 `sku_board/`，先按仓库README创建根目录 `.venv` 并启动8793，再运行本目录 `start.ps1` 启动8795。工作区正在运行的原目录不受本次打包影响。

# COD 对话创作室 · 本地独立版

启动：PowerShell 执行本目录 start.ps1。访问 http://127.0.0.1:8795/ 。
启动器固定使用工作区 `.venv\Scripts\python.exe`，不再选择PATH里的全局Python。启动前执行 `server.py --check-compiler` 验证真实编译器及依赖；更换运行环境时，在现有任务完成后运行 `start.ps1 -Restart`。`/health` 返回compilerReady、projectVenv和pythonVersion；缺少依赖的进程不再作为正常服务启动。
旧面板 http://127.0.0.1:8793/ 必须运行；这里通过固定本地代理复用其登录、导演和图片任务服务，不修改旧项目文件。

顶部「创作模式」支持三种独立引擎流程：
- COD 国家专区：原有默认14张，支持8–30张，750×1000。
- 日本产品落地页25图：固定25张、日本/日语，1500×2000，使用 `jp-landing-page-25`。
- COD详情图：默认22张，可选12、16、20、22张，750×1000，使用 `cod-country-detail-12`（引擎兼容键名，不表示固定12张）。
每个对话保存独立模式；旧会话仍按 COD 国家专区加载。有内容的对话切换模式会保存旧记录并新建对话，空白对话切换保留已上传参考图。运行中禁止切换。策划、编译预览、逐页生成与重试使用同一模式参数；不匹配的引擎响应会暂停处理。
COD 两种模式的市场选择与原面板同步：韩国、日本、美国、英国、德国、匈牙利、波兰、西班牙、墨西哥、法国、捷克、台湾、香港、泰国、越南、马来西亚、新加坡、菲律宾、印度尼西亚，共19个国家/地区。语言沿用各自原引擎本土化配置；日本25图仍锁定日本。
默认只允许本机 `127.0.0.1:8795` 访问。需要通过隧道或反向代理对外发布时，用环境变量把额外来源加入白名单：
`COD_STUDIO_ALLOWED_HOSTS=panel.example.com,panel.example.com:443`、`COD_STUDIO_ALLOWED_ORIGINS=https://panel.example.com`。
公网与本地是不同浏览器存储来源，历史对话不会自动互通。

上传产品图，输入市场/卖点，自动展示产品分析、逐页方案表、文字化风格锚点和编译后的基础提示词。
新会话默认勾选“方案完整后自动生成图片”，发送会消耗分析和生图额度；取消勾选或输入“先出方案”则等待确认。
显式的“共14张”“主图8张、详情22张”会从需求读取。目标市场始终以下拉框为准，提示词中提到其他国家的商品产地或参考排版不会改写选择。要换目标市场请先调整下拉框；已有方案需新对话。未明确时使用可见页数设置。
两种COD共用完整19市场本土化约束：分析、逐页七层导演和最终Prompt均绑定所选市场，区分语言/文字、日常人物造型和场景；产品及明确人物身份保留，不用脸型推断国籍、不强制单一种族或肤色。旧方案在本次规则更新后提示“更新市场方案”，原图与任务保留，继续同步不受影响。重新策划会调用上游导演，原有缓存版本仅在COD范围更新。
缺页最多续写5轮，连续2轮无进展即停止；方案或提示词编译不完整时不提交图片。
导演时限耗尽单独显示为待续写，不把尚未发出的请求计为模型故障。各初始批次先执行，拆分重试排到后续；每批成功保存在线七层Brief检查点，下一轮从缺页继续。真实超时/断流仍保留在可展开的请求记录中。额度可用不代表连接、上游排队和请求时限一定正常。
编译预览通过已登录代理响应调用现有本地编译器，不额外调用AI。节点提交仍会追加模型适配及参考图约束。
完整方案编译失败时可点“重试本地编译（不调用AI）”，重新编译已保存的逐页方案，不重新策划，也不自动生成图片。编译器真实错误分类和编号会显示在页面，traceback保存在8795的stderr.log；依赖问题不再提示用户反复续写。新编译接口继续验证原引擎登录与角色权限。
风格锚点展示用户明确色值和线上Brief的配色/风格层，不把首图位图复用给其他页面。
对话支持“第3张……”记录该页补充要求，也可直接编辑页面要求。
生成结果逐页返回；刷新后点击同步已有任务，不重复提交。未确认结果的请求不会自动重试。
没有成图AI质检。当前采用串行生图，避免一次提交大量请求。线上逐页导演默认3批并发，每批仍是完整七层Brief；检测到限流/拥堵后，补偿重试降低并发，后续轮次默认2批。管理员显式并发配置仍优先。
同一对话完整方案按原文、模式、市场、页数/尺寸、参考文件名/类型及内容SHA256验证复用；命中时不再发导演请求。输入变化或旧方案缺少签名时仍走引擎校验。“重新AI策划”确认后绕过完整缓存，仅首轮强制重做，后续缺页续写复用新进度；更换导演模型后希望重做时也使用该按钮。生成单页仍只提交该页。
本地提示词编译增加8项内存LRU缓存，键包含完整原文、方案、市场、尺寸和版本，返回数据相互隔离；重启清空。页面展示上游策划耗时（含分析与逐页）、本地编译耗时及缓存命中；实际端到端速度仍取决于上游。

会话与参考文件保存在本浏览器 IndexedDB，按账号隔离展示。清除站点数据会删除这些本地会话。
左侧历史对话支持右键、每行「⋯」或 Shift+F10 打开操作菜单：重命名（1–80字符）、收藏/取消收藏、确认删除。收藏显示在列表前面；手动名称不被产品需求覆盖。删除只清除当前站点浏览器里的对应对话、参考文件与任务索引，没有恢复入口；后台生成图片不删除，后台任务不取消。存在待处理任务时弹窗会额外提醒先同步保存。运行中暂禁历史管理以保护正在提交的任务。
模型、节点、任务与生成图片仍使用旧引擎存储。不是一套完全独立的生图后端。
这不是通用自由对话模型：输入整套需求用于AI策划；单页修改命令存为生成约束。
更换整套需求需新建对话。输入“开始生成”“继续生成”“续写方案”可推进对应步骤。
暂停只停止后续步骤，不撤销已提交的上游任务；刷新后仅同步已有任务，不自动续跑计费操作。
新增“取消本次任务”：向后台发送owner隔离的持久取消标记，停止未提交请求、排队任务和后续重试；操作编号随对话保存，刷新后仍可取消。已提交给上游且不支持撤销的请求可能继续执行并计费，当前已提交请求的结果仍会保存。取消失败明确提示未确认，可再次点击；不通过刷新或删除对话冒充后台取消。原面板也有固定取消按钮。
导出文件包含原始需求、文字风格和逐页提示词。浏览器端单页修改仍是记录明确补充要求，不是通用聊天助手。

验证：`python -m unittest discover -p 'test_*.py'`；`node test_workflow.cjs`。
浏览器回归（需 Playwright）：`node test_browser.cjs` 和 `node test_history_browser.cjs`。使用隔离浏览器与模拟登录接口，不操作真实账号记录，不提交付费请求。
