# 自动对话落地页工作流

主体修改在8795独立项目。共享8793现有COD模型分析、逐页Brief和生图服务，不修改其配置或页面。
兼容修复：底层COD国家专区接受8–30之间的明确页数，避免14自动变30；保留原37页档位。

1. 用户上传原图、输入完整需求，保留原文；解析明确市场和总页数，其他情况使用界面设置。
2. 公司模式策划返回产品摘要、来源卖点、逐页摄影方向、七层Prompt与产品DNA。
3. 用表格展示真实返回数据；风格锚点来自用户明确色值和AI风格层，无新增首图参考。
4. 已授权的上游策划响应才可调用本地编译器，返回每页基础提示词；禁止将JSON脚本冒称实际Prompt。
5. 最多5次缺页续写、连续2轮停滞即停。完整Brief且编译成功且用户已开启自动生图才提交图片。
6. 每页提交前持久化状态；获得任务ID后立即持久化；网络错误标记待核对，不自动重提。
7. 成功逐张展示。明确失败才支持重试；运行中或待同步的任务先查询旧ID。
8. 不调用任何生成后AI质检。暂停不会取消上游请求或隐式刷新任务。

限制：方案请求仍依赖既有引擎的同步接口，UI阶段显示本轮已返回数据而非虚构细粒度进度。
刷新期间若提交完成却尚未记录ID，用户需到原面板核对；尚未实现服务端幂等提交账本。
风格摘要不是新AI调用，依赖实际已返回风格层。缩略图视觉一致性需真实套图验证，测试不占用生图额度。
